# Research notes

- Official Agent Skills evaluation guidance describes paired with-skill and baseline runs, and recording result quality, token count, and duration: https://github.com/agentskills/agentskills/blob/main/docs/skill-creation/evaluating-skills.mdx
- Observation: quality and resource use are separate signals. Project judgment: paired aggregation by case ID makes that tradeoff easier to inspect.
- This tool does not run model evaluations and cannot make causal claims from captured records.
